# The Blackhearts

Player documents for **The Blackhearts**, a grimdark D&D campaign set in the Gloombough.

The site is plain HTML hosted on GitHub Pages. The only build step is a small script that turns backstory Markdown files into pages.

## Layout

| Folder | What's in it |
| --- | --- |
| `docs/lore/` | Campaign overview, the faction guide, the regional gazetteer |
| `docs/mechanics/` | House rules: character creation, combat, crafting, durability, Ranger Arts |
| `docs/backstories/` | Player backstories as Markdown |
| `backstories/` | The web page for each backstory, generated by `build_backstories.py` |
| `assets/` | Stylesheet, PDF cover images, the Gloombough map |

## Adding a document

1. Put the PDF in the right folder under `docs/`, using a lowercase file name with dashes, like `docs/lore/house-ardane.pdf`.
2. Copy one of the cards in `index.html` into the matching section and change the links, title, description and page count. Add a cover image to `assets/covers/` (a JPEG of the first page, about 520 pixels wide) and point the card's `<img>` at it.
3. Commit and push. The site updates within a couple of minutes.

## Adding a backstory

1. Put the Markdown file in `docs/backstories/`, named like `firstname-lastname.md`. Start it with `# Character Name`, an optional quote, and include an `## At the Table` section with the quick summary.
2. Run `python build_backstories.py` (needs `pip install markdown`). It creates `backstories/firstname-lastname.html` and moves the At the Table section to the top of the page, so readers see the summary before the full story.
3. Copy the Bowyer Campbell card in the Player Backstories section of `index.html` and change the quote, name, description and link.
4. Commit and push.

Everything here is public. Keep DM-only material out of this repository.
