# The Blackhearts

Player documents for **The Blackhearts**, a grimdark D&D campaign set in the Gloombough.

The site is plain HTML hosted on GitHub Pages. The only build step is a small script that turns backstory Markdown files into pages.

## Layout

| Folder | What's in it |
| --- | --- |
| `docs/lore/` | Campaign overview, the faction guide, the regional gazetteer |
| `docs/mechanics/` | House rules: character creation, combat, crafting, durability, Ranger Arts |
| `docs/backstories/` | Player backstories as Markdown |
| `backstories/` | The web page for each backstory, generated by `build_backstories.py` |
| `assets/` | Stylesheet, PDF cover images, the Gloombough map |
| `tools/` | The Tools page: trackers for the house rules (see below) |
| `tests/` | Checks for the Tools page |

## Adding a document

1. Put the PDF in the right folder under `docs/`, using a lowercase file name with dashes, like `docs/lore/house-ardane.pdf`.
2. Copy one of the cards in `index.html` into the matching section and change the links, title, description and page count. Add a cover image to `assets/covers/` (a JPEG of the first page, about 520 pixels wide) and point the card's `<img>` at it.
3. Commit and push. The site updates within a couple of minutes.

## Adding a backstory

1. Put the Markdown file in `docs/backstories/`, named like `firstname-lastname.md`. Start it with `# Character Name`, an optional quote, and include an `## At the Table` section with the quick summary.
2. Run `python build_backstories.py` (needs `pip install markdown`). It creates `backstories/firstname-lastname.html` and moves the At the Table section to the top of the page, so readers see the summary before the full story.
3. Copy the Bowyer Campbell card in the Player Backstories section of `index.html` and change the quote, name, description and link.
4. Commit and push.

## Tools page

`tools/index.html` holds trackers for the house rules, one tab per rules document: Character (creation and trainer-quest advancement), Combat (death throes, near-death exhaustion, bleeding, called-shot injuries, attack modifiers, percentile crits, block/parry/dodge), Gear & Durability, Crafting, and Ranger Arts. Players can keep several characters. Everything is saved in their own browser (`localStorage`), so nothing is sent anywhere and it doesn't carry between devices.

| File | What it does |
| --- | --- |
| `assets/tools/rules.js` | The rules tables and formulas, copied from the PDFs. Change numbers here when a rule changes. |
| `assets/tools/core.js` | Saving, undo, the character list, tabs. |
| `assets/tools/<tab>.js` | One file per tab. |
| `assets/tools.css` | Styles for the Tools page. |

Where the PDFs disagree or stop short, the tools follow these choices. Change them in `rules.js` if the DM rules otherwise:

- A crafting total of exactly 80% is Good (the Crafting doc), not Masterwork (the older Character Creation example).
- An item's grade for repairs is its craftsmanship grade.
- Three Poor layers add up to -50% durability; the item is held at 1 and flagged for the DM.
- Injury thresholds round up (33 max HP gives a head threshold of 7).
- 1.5x critical damage rounds down.
- Ranger slots, prepared counts and free Predator's Focus uses follow the 2024 Ranger table, and the page lets you override them.

### Testing

```
node --test tests/*.test.js     # rules checked against the PDF examples; needs only Node
node tests/browser-check.js     # drives the page in Chromium; needs `npm install playwright`
```

Pass a folder to the browser check (`node tests/browser-check.js shots/`) to save desktop and phone screenshots of every tab.

Everything here is public. Keep DM-only material out of this repository.
